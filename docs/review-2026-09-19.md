An in-band run remained alive with memory-manager timer output after assertions completed. Timer cleanup in the tests needs follow-up; the passing assertion count does not establish clean shutdown.

**Backup-preview context:** while a backup diff was active, the sidebar and formatting panel selected the virtual `current.twb` preview. Refocus the original workbook before another edit. Mapping preview documents back to their source workbook would improve this flow.

The screenshots verify the captured extension workflows. This review did not validate Copilot-generated answers, Tableau Desktop rendering, external data connections, or Marketplace publication.
